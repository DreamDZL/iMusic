# iMusic 2.1 发布候选

本版本改善聚合搜索、播放交互和听歌记录同步。

- 四平台聚合搜索覆盖 QQ 音乐、网易云、酷我和酷狗，支持合并匹配录音和选择播放来源；改进搜索框聚焦、选中和键盘提交。
- 优化播放页交互式收起、封面动画和滑动切歌；受支持设备在播放器交互期间会请求更高刷新率。
- 改进推荐封面、播放错误提示和网易云听歌记录同步。
- 目录和 LX 播放支持上述四个平台；旧资料库条目保留原平台标识。音源可用性取决于所导入的脚本和服务状态。

本说明以远程 `v2.0` 指向的提交 `f238f8628a3c484c3831abacafea660ceec937f4` 与候选基础提交 `db0f82ba9ed59d4f5b5684b91cb53790db06ff22` 的差异为依据。
